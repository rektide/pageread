# Pageread design reading map

## Integrating architecture

- [Virtual page blackboard](./blackboard/README.md) — the larger thesis and its
  small parts: a private item graph, worker selectors, received/work children,
  explicit rejection and completion records, and an owned view that leaves the
  source page DOM unaugmented by default.

## Product and installation direction

- [One host, discoverable scripts](./script-runtime/design0.gpt6a.md) — the
  human's shift toward a script-installing reader extension, ATProto discovery
  by origin/host/domain, local lifecycle tools, collections and a companion PWA.
  Bespoke extension generation remains a secondary packaging target. Includes
  current installation APIs and proposal-status distinctions.

## Ontology and portable knowledge

- [Blackboard production](./observation-queries/blackboard0.gpt6a.md) — input
  matching and proactive derived content around sensor routines; pending
  OTLP/OTAP representations, explicit export actions and Oxigraph receivers.

- [Sensor routines](./observation-queries/sensor-routines0.gpt6a.md) — a focused
  authoring direction: sensors as queries producing values, HTML/XML recipe
  structure, executable module leaves, and templates waiting for keyed entries.
- [Observation queries and annotations](./observation-queries/README.md) — query
  procedures, nested selectors, microdata occurrence structure, identified result
  batches, an agentic annotation kit, and data-consuming factories. Includes FX's
  rediscovery of DepIn-O/OOC-O and a verified RDF/CSS/annotation example.
- [Ontology-forward pageread](./ontology/README.md) — SOSA/PROV observations,
  explicit resolution, OTel execution, Oxigraph hosts, reactive views, and
  portable dataset bundles. Includes a queryable TriG example and dump/reload
  verification. Start here for the ontology-forward direction.

## Toolkit and interface inquiry

- [Original OTel-microdata architecture](./otel-microdata/draft0.glm53m.md) — the
  trace-first schema, signal router, MIME store, indexer, and extension DSL sketch;
  preserves the finder split and checkpoint lesson.
- [Independent design module](./tabula-rasa/README.md) — a capability-driven
  reset with independent browser/content research and contract reviews. Its
  independence and evidence boundaries are documented in that module.

## Reactive storage and resolution

- [AM round one](./reactive-indexes/draft0.gpt6am.md) — outside diagnosis of
  committed changes, coverage, view lifecycle, and shared search infrastructure.
- [AM round two](./reactive-indexes/draft1.gpt6am.md) — scoped claims, source
  authority, exact-document preservation, graph projection, and capture-first
  sequencing; explicitly revises several round-one recommendations.
